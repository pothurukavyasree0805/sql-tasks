6. From a students table (columns: name, grade, score), write a query to sort students
first by grade ascending, then by score descending within each grade. Also explain
what happens to any NULL scores in ascending vs descending sort.

MySQL  localhost:33060+ ssl  d13  SQL > select name, grade, score
                                      -> from students
                                      -> order by grade asc, score desc;
output:
+-------+-------+-------+
| name  | grade | score |
+-------+-------+-------+
| Pooja | A     |    95 |
| Asha  | A     |    90 |
| Kiran | A     |    85 |
| Ravi  | B     |    75 |
| Sneha | B     |  NULL |
| Anil  | C     |    60 |
+-------+-------+-------+
Null comes first in ascending order and last in descending order.
